Minha Página Web

Projeto desenvolvido para praticar HTML, CSS e Git.

Sobre o projeto

Esta é uma página simples criada como atividade de introdução ao desenvolvimento web. O objetivo é aplicar conceitos básicos de HTML e CSS e publicar o projeto em um repositório no GitHub.

Conteúdos estudados

HTML

O HTML é utilizado para organizar e estruturar o conteúdo de uma página web, utilizando elementos como títulos, textos, links e seções.

CSS

O CSS é responsável pela aparência da página, permitindo alterar cores, espaçamentos, tamanhos, fontes e a organização dos elementos.

Git e GitHub

O Git permite controlar as versões de um projeto, enquanto o GitHub possibilita armazenar e compartilhar o repositório pela internet.

O que aprendi

Com esta atividade, pratiquei a criação da estrutura de uma página, sua estilização e a organização dos arquivos para versionamento com Git.
