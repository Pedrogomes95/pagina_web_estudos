# Página Web - HTML, CSS e Git

Projeto simples desenvolvido para praticar os conceitos introdutórios de HTML, CSS e Git.

## Conteúdo

- Estrutura básica em HTML
- Estilização com CSS
- Layout responsivo
- Organização do projeto para publicação no GitHub

## Como executar

Baixe ou clone o repositório e abra o arquivo `index.html` no navegador.
